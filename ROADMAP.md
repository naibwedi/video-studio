# Roadmap

Done: `studio draft`, tagged clip library, thumbnails, teaser, quality check, native subscribe pop-ups (v0.2); the local dashboard `studio ui` (v0.3).

Next, in rough priority order. Tell Claude which one to build.

1. **YouTube results** (read-only): views, likes, comments next to each project in the dashboard, plus your own notes.
2. **Publish from the dashboard**: upload with title, description, tags and thumbnail kept in the project.
3. **GPU encoding**: already built in; switches on once the NVIDIA driver is 610 or newer (`studio doctor` tells you).
4. **Faster final pass**: join shots in groups, in parallel.
5. **Changeable animated end card** (title and handle from project.json, like the pop-up already is).
6. **Find clips from the dashboard** (search a stock site and add to the library without leaving the page).
